# Edição e Correção de Polígonos no SIGEF

**Tema:** Técnicas de edição de vértices e correção de erros em desenhos de polígonos no SIGEF

## Regras técnicas

- Desabilitar camadas desnecessárias (como reserva legal) para melhor visualização durante a edição
- Habilitar a camada de remanescente ou referência que será usada para corrigir o polígono
- Usar a ferramenta de edição para identificar e corrigir vértices incorretos
- Cada vértice é representado por um nó (círculo) que pode ser movido individualmente
- Clicar no nó do vértice permite selecioná-lo e reposicioná-lo
- Para adicionar um novo vértice: clicar sobre a linha do polígono para criar um nó adicional
- Após as correções, sair do modo de edição e salvar as alterações

## Pendências comuns / erros do SIGEF

- Vértices desalinhados com a vegetação nativa ou perímetro — causa: imprecisão no desenho inicial — solução: usar ferramenta de edição para ajustar cada nó individualmente
- Polígono não alcança o perímetro esperado — solução: adicionar vértices e deslocar a linha até a feição correta

## Observações importantes

- Erros podem não ser perceptíveis durante o desenho inicial; revisar sempre posteriormente
- A ferramenta de edição permite trabalho preciso vértice a vértice
- Sempre salvar após concluir as correções
